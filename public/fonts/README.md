# Emerald Bayou loading-screen fonts

- Le Murmure Regular by Jeremy Landes, distributed by Velvetyne under the SIL Open Font License 1.1. Source: https://velvetyne.fr/fonts/le-murmure/
- Barlow Condensed by Jeremy Tribby, distributed under the SIL Open Font License 1.1.
- Yellowtail by Astigmatic, distributed under the Apache License 2.0.

The loader uses Le Murmure for the main title, Yellowtail for “Bayou,” and Barlow Condensed for the scene and progress copy. The corresponding license files are kept in this directory.
